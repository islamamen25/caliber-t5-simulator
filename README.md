# CALIBER T5 Simulator

محاكي تعليمي مستقل لروبوت CALIBER® T5: بيسوق، ويطلع سلم 45°، ويمد ذراعه ويمسك طرد ويلف في مكانه. مش من الشركة المصنّعة ولا تابع لها.

An independent interactive 3D teaching model of the CALIBER® T5 robot, in Arabic, not made by or connected to the manufacturer. Masses inside, power and friction are model values, not measurements.

Open it: https://islamamen25.github.io/caliber-t5-simulator/
